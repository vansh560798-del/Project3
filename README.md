# C Pattern Printing – Project 3

A beginner-friendly **C programming project** containing 7 different pattern-printing programs using `for` loops and basic conditional statements.

## 📌 About the Project

This project was created to practice the fundamentals of **C programming**, especially:

* `for` loops
* Nested loops
* `if-else` statements
* Number patterns
* Binary patterns
* Character/symbol patterns
* Basic program logic

All patterns are implemented in a single C file: `Project3.c`.

## 🔢 Patterns Included

The project contains the following 7 questions:

### Q1 – Number Triangle

Prints a simple increasing number pattern.

### Q2 – Continuous Number Pattern

Prints numbers continuously starting from `11`.

### Q3 – Reverse Number Pattern

Prints a decreasing pattern with spaces for alignment.

### Q4 – Binary Pattern

Prints a pattern containing alternating `1` and `0`.

### Q5 – Palindromic Number Pattern

Prints numbers in an increasing and decreasing arrangement to form a symmetric pattern.

### Q6 – Number Pyramid

Prints a pyramid-like pattern using increasing and decreasing numbers.

### Q7 – Letter P Pattern

Uses `*` symbols and conditions to create the letter **P**.
